# Universal iDRAC Console

**Conzex product** — one web UI for Dell **iDRAC 6–9**. No Java on user PCs.

| iDRAC | Remote console |
|-------|----------------|
| 8 / 9 | HTML5 in browser |
| 6 / 7 | noVNC (Java runs in Docker on the server) |

## Distribution

Universal iDRAC Console is **proprietary software** from **Conzex Global Private Limited**. Access is provided under license as a **fully cloud-hosted** service—operators sign in to Conzex infrastructure and install the **UiDRAC agent** on their LAN to reach iDRAC.
