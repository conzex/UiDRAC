# Application versioning

- **Current version:** stored in `.idrac-version-state.json` and `packages/shared/src/version.ts` (`APP_VERSION`).
- **Initial release:** v1.0.0
- **Automation:** each git commit with staged changes runs `scripts/version-track.mjs` (via the `pre-commit` hook installed by `pnpm prepare`).
- **Bump rule:** after **10** tracked changes, the **PATCH** segment increments (e.g. v1.0.0 → v1.0.1) and the change counter resets.
- **Manual run:** `pnpm version:track`
- **Displayed in:** web footer, API `GET /api/` and `GET /api/health`.

Do not edit `packages/shared/src/version.ts` by hand; it is regenerated by the version script.
